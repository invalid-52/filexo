## ⚡ Features

- **Advanced Pattern Engine** — Build custom names with rich tokens like `{name}`, `{date}`, `{time}`, `{yyyy}`, `{n}`, `{index}`, `{random}`, and more.
- **Find & Replace** — Supports plain text and full regular expressions.
- **Case Transformations** — lower, UPPER, Title, camelCase, PascalCase, kebab-case, snake_case.
- **Smart Numbering** — Configurable start value and zero-padding.
- **Extension Control** — Keep, lower, UPPER, set to custom, or remove completely.
- **Intelligent Conflict Resolution** — Auto-resolve duplicates seamlessly or flag conflicts before export.
- **Batch Export** — Download files individually or package them all into a single `.zip` file instantly.
- **Zero-Friction UI** — Drag-and-drop interface with live before/after previews, light/dark modes, and fine-tuned animation controls.

## 🔒 100% Private

Your files never leave your device. FILEXO runs entirely locally using modern browser APIs. No uploads, no servers, absolute privacy.

## 💻 Tech Stack

- **Framework**: React (Vite)
- **Styling**: Tailwind CSS v4 (Custom UI tokens, Dark/Light modes)
- **Archiving**: JSZip (Client-side ZIP packaging)

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/invalid-52/filexo.git

# Enter the project directory
cd filexo

# Install dependencies
npm install

# Start the development server
npm run dev
```
